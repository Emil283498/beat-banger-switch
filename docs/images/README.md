# Screenshots

Положите сюда скриншоты порта (например `menu.png`, `gameplay.png`) и
добавьте их в `README.md`:

```markdown
![Main menu](docs/images/menu.png)
```

> Не публикуйте скриншоты, содержащие откровенный контент игры, если
> репозиторий должен оставаться безопасным для GitHub. Соблюдайте правила
> сообщества и авторские права.
